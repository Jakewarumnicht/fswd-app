# Solution Elements

## **3.1 Grundidee von Uni2Work**

Uni2Work ist eine spezialisierte Webplattform, die Studierende anhand ihrer fachlichen Interessen und Fähigkeiten mit passenden Unternehmen und Werkstudentenstellen verbindet.

Die Lösung konzentriert sich auf drei Vorteile: **gezieltere Stellensuche, kompetenzbasiertes Matching und zusätzliche Sichtbarkeit für Unternehmen.**

---

## **3.2 Zentrale Funktionen**

| Solution Element                 | Nutzen                                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Studierendenprofil**           | Studiengang, Fachsemester, Interessen, Skills und Kenntnisse aus Hochschulmodulen erfassen                   |
| **Keyword-Matching**             | Fachliche Überschneidungen zwischen Studierenden und Stellen anhand eines Match-Prozentwerts sichtbar machen |
| **Gezielte Filter**              | Nach Standort, Studiengang, Arbeitsmodell, Schlagwörtern und weiteren Kriterien suchen                       |
| **Automatischer Website-Import** | Unternehmensinformationen und Stellenangebote ohne zusätzliche manuelle Pflege übernehmen                    |
| **Unternehmensprofile**          | Auch bisher unbekannte Arbeitgeber entdecken, einschließlich Unternehmen ohne aktuelle Stellenangebote       |
| **Direkte Bewerbung**            | Über einen Link direkt zur Original-Stellenanzeige des Unternehmens gelangen                                 |
| **Dashboard und Merkliste**      | Passende Unternehmen entdecken und interessante Arbeitgeber speichern                                        |

---

## **3.3 Zusammenhang zwischen Problemen und Lösung**

Uni2Work setzt gezielt an den zuvor beschriebenen Problemen an.

Studierende, die auf allgemeinen Jobplattformen viele unpassende Stellen finden, erhalten eine auf Werkstudententätigkeiten spezialisierte Suche. Das Keyword-Matching berücksichtigt ihre fachlichen Kenntnisse und hebt Stellen mit gemeinsamen Schlagwörtern hervor.

Unternehmen, insbesondere KMU, erhalten eine zusätzliche Möglichkeit, von Studierenden entdeckt zu werden. Durch die geplante automatische Übernahme öffentlich zugänglicher Informationen müssen sie dafür keine eigenen Accounts anlegen oder Stellen zusätzlich pflegen.
